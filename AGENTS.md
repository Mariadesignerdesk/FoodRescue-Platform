# FoodRescue — Project Instructions

## Project
FoodRescue is a food donation and waste reduction platform connecting restaurants, bakeries, grocery stores and charities.

Tagline: Good food deserves a second chance.

## Technology
- React + Vite
- TypeScript
- Tailwind CSS v4
- React Router
- Lucide React
- Recharts
- Supabase (Phase 2)

## Brand Colors
- Forest Green: #173D31
- Sage: #E9F0E6
- Cream: #FAF8F1
- Harvest Orange: #E89B55

## Design Direction
Create a premium sustainability startup experience.
Use editorial food photography, elegant typography, generous spacing, modern cards and responsive layouts.

## Coding Standards
- Use TypeScript.
- Build reusable components.
- Keep a clean folder structure.
- Use Lucide React icons.
- Use accessible forms.
- Validate user inputs.
- Handle loading, errors and empty states.
- Avoid unnecessary dependencies.
- Keep code maintainable.

## Backend Rules
Supabase must be the real persistent backend.
Never substitute LocalStorage for database functionality.
Never expose credentials or secrets.
Use environment variables.
